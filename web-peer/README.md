# LocalSend 電腦端（web-peer）

在 Windows 電腦上執行的 LocalSend 相容節點，用瀏覽器操作，可以和手錶（或手機）上的 LocalSend App 互傳檔案與文字。

- 用 Node.js 寫成，除了產生憑證用的 `node-forge` 之外不需要其他套件。
- 協定與 LocalSend v2.2 相容：HTTPS 加密、連接埠 53317、多播探索，App 不需要改任何設定。
- 網頁介面只在本機 `http://127.0.0.1:53318` 開放，區網裡的其他裝置看不到。

協定細節請見 [PROTOCOL.md](PROTOCOL.md)。

## 需求

- Windows 10 / 11
- [Node.js](https://nodejs.org/) 18 以上（建議安裝 LTS 版）
- 電腦和手錶連在**同一個 Wi-Fi**

## 啟動

1. 雙擊 `start.bat`。
2. 第一次執行會自動安裝套件（需要網路），並在 `data/` 產生這台電腦專用的憑證。
3. 瀏覽器會自動打開 `http://127.0.0.1:53318`。
4. 要結束時，關掉黑色的命令列視窗，或在視窗裡按 `Ctrl+C`。

也可以在命令列裡手動執行：

```bat
cd web-peer
npm install
node server.js --open
```

## Windows 防火牆（很重要）

第一次啟動時，Windows 會跳出「Windows 安全性警訊」詢問是否允許 Node.js 存取網路。

- 如果你的 Wi-Fi 網路設定檔是 **「公用網路」**，請在視窗中**勾選「公用網路」**再按「允許存取」。
  只勾「私人網路」的話，手錶會找不到電腦。
- 比較建議的做法：到「設定 → 網路和網際網路 → Wi-Fi → （你的網路）」把網路設定檔改成 **「私人網路」**。
- 需要放行的是 **TCP 53317** 與 **UDP 53317** 的輸入連線。

如果當時按了「取消」，可以到「控制台 → Windows Defender 防火牆 → 允許應用程式通過 Windows 防火牆」找到 `Node.js JavaScript Runtime`，把對應的網路類型打勾。
也可以用系統管理員身分開啟 PowerShell 執行：

```powershell
New-NetFirewallRule -DisplayName "LocalSend web-peer TCP" -Direction Inbound -Protocol TCP -LocalPort 53317 -Action Allow -Profile Any
New-NetFirewallRule -DisplayName "LocalSend web-peer UDP" -Direction Inbound -Protocol UDP -LocalPort 53317 -Action Allow -Profile Any
```

## 使用方式

### 找到手錶

- 在手錶上打開 LocalSend，切到「傳送」頁，電腦的名稱就會出現在手錶的清單中，手錶也會出現在網頁的「附近的裝置」。
- 找不到時，按網頁上的「重新掃描」：會再發一次多播宣告，並逐一詢問同網段（/24）的每個 IP。
- 網頁右上角可以修改「我的裝置名稱」，手錶上會顯示這個名稱。

### 從電腦傳給手錶

1. 在「附近的裝置」點選手錶。
2. 把檔案拖進「傳送」區，或點一下選擇檔案（可多選）。檔案會先暫存到 `data/staging/`，同時計算 SHA-256。
3. 按「傳送」，然後**在手錶上按「接受」**。手錶預設只自動接受「我的最愛」裡的裝置，所以第一次一定要手動接受。
   想以後免按，可以在手錶上把這台電腦加入「我的最愛」。
4. 進度會即時顯示；傳送中可以按「取消」。
5. 切到「文字」分頁可以直接傳一段文字，手錶會顯示成訊息。

### 從手錶傳給電腦

1. 在手錶上選擇檔案，再選這台電腦。
2. 網頁會跳出對話框，顯示寄件裝置和檔案清單，按「接受」或「拒絕」。
   超過 120 秒沒有回應會自動拒絕（可在 `data/config.json` 調整 `acceptTimeoutSec`）。
3. 接收進度會顯示在右側「接收」區，也可以按「取消」中止。
4. 手錶傳來的文字訊息會直接顯示在「收到的文字訊息」，可以一鍵複製。

> 同一時間只能有一個傳入的傳輸，傳輸期間其他裝置要傳檔會收到「對方忙碌」。

## 檔案存在哪裡

- 收到的檔案預設存在 `web-peer\received\`。網頁上的「開啟資料夾」按鈕會用檔案總管打開它，清單裡的檔名可以直接下載。
- 同名檔案不會被覆蓋，會自動改名成 `名稱 (1).副檔名`。
- 對方傳來的檔名會先清理：去掉 `..`、磁碟代號、Windows 不允許的字元與保留名稱（如 `CON`），確保檔案只會寫進收件資料夾裡。
- 要改收件位置，可以編輯 `data/config.json` 的 `receiveDir`（相對於 `web-peer` 資料夾，或填絕對路徑），
  或在啟動前設定環境變數 `LOCALSEND_RECEIVE_DIR`。

`data/` 資料夾的內容：

| 檔案 | 說明 |
|---|---|
| `config.json` | 裝置名稱、收件資料夾、接受逾時、宣告間隔等設定 |
| `cert.pem` / `key.pem` | 這台電腦的自簽憑證與私鑰。**請勿刪除**，否則 fingerprint 會改變，手錶上的「我的最愛」會失效 |
| `fingerprint.txt` | 憑證 fingerprint（手錶用它辨識這台電腦） |
| `staging/` | 待傳送檔案的暫存區，每次啟動時清空 |

## 疑難排解

| 狀況 | 可能原因與解法 |
|---|---|
| 雙擊後顯示「找不到 Node.js」 | 安裝 Node.js LTS 後重新開機或重新登入，再雙擊一次 |
| 「連接埠 53317 已被占用」 | 電腦上已經開著官方 LocalSend 或另一個 web-peer 視窗，請先關掉 |
| 「網頁介面連接埠 53318 已被占用」 | 已經有一個 web-peer 在執行，直接打開 `http://127.0.0.1:53318` 即可 |
| 手錶找不到電腦 / 電腦找不到手錶 | 1. 確認在同一個 Wi-Fi（不是訪客網路）。2. 檢查防火牆，見上方說明。3. 按「重新掃描」。4. 有些路由器開了「AP 隔離 / 用戶端隔離」，會讓同網路的裝置互相看不到，需到路由器設定關閉 |
| 一直停在「等待對方接受」 | 請在手錶上按「接受」。手錶螢幕若已關閉，先喚醒手錶 |
| 顯示「對方正在進行其他傳輸」 | 手錶一次只能收一個傳輸，等它結束或在手錶上取消後再試 |
| 顯示「對方憑證 fingerprint 不符」 | 手錶重新安裝過 App（憑證變了）。按「重新掃描」更新裝置資料 |
| 傳輸失敗、檔案不完整 | Wi-Fi 訊號不穩。重新傳一次即可；不完整的檔案不會留在收件資料夾 |
| 網頁顯示「與本機服務中斷」 | 命令列視窗被關掉了，重新雙擊 `start.bat` |
| 電腦有多張網卡（VPN、虛擬機） | 程式會在所有 IPv4 網卡上宣告；若仍有問題，暫時關閉 VPN 再試 |

命令列視窗會顯示詳細記錄（探索、註冊、傳輸結果），回報問題時可以一併提供。
